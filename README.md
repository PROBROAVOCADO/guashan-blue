# 卦山藍網站

純靜態 HTML、CSS 與 JavaScript。內容由原本的 Google 試算表，透過 GAS 提供。

## 試算表與編輯方式

- 原試算表：https://docs.google.com/spreadsheets/d/1VhSULsJ6Y232qW6BspXRoo_Tfb5fGEXHocreG2USKNQ/edit
- 依序為「首頁主視覺、品牌故事、產品、常見問題、訂購與預約、聯絡我們」。
- A 欄為中文參數名稱；B 欄為網站內容／圖片網址／連結；C 欄為說明。
- 日常只修改 B 欄。中文名稱與分頁名稱仍是識別欄位，請保留既定拼法。
- 隱藏的「工作表1」為分類前備份，不會讀入正式網站。
- 維持同一份試算表與同一個 GAS 部署，因此不需更換共享網址或前端 GAS_URL。

## 中文參數名稱

| 分頁 | A 欄名稱 |
| --- | --- |
| 首頁主視覺 | 首頁小標題、首頁主標題、首頁簡介 |
| 品牌故事 | 品牌故事標題、品牌故事內文1／2、園區資訊1～3數值／名稱、果園照片1～7 |

| 訂購與預約 | 底部邀請標題、訂購網址、採果預約網址 |
| 聯絡我們 | Facebook網址、Instagram網址、LINE網址、園區地址、導航按鈕文字、顯示位置資訊 |

「1～3」表示每個編號各一列，例如「產品1名稱」、「產品2名稱」。
果園照片可繼續新增「果園照片8」、「果園照片9」等，會依編號排序。
其他新增元件仍需前端提供對應版面；目前 FAQ 版面只有前四題。

## 程式對應

- content-keys.js：中文名稱與英文內部 key 的共用對照規則。
- index.html：先載入 content-keys.js，再載入 script.js。
- script.js：支援中英文 API 欄位，並沿用原 GAS /exec 網址。
- apps-script/Code.gs：已整合相同的對照規則，提供六分頁讀取與一次性中文化函式。

GAS 將 A 欄中文轉回原本英文 key，保留 { content, links } 的回傳格式。
因此現有線上前端與新版前端都能讀取；HTML 的 data-content 等內部 key 保持穩定。
修改對照規則時，需同步更新 content-keys.js 與 Code.gs 內的同一段規則。

## 發布

網站仍使用既有 GitHub Pages 與 baguablueberry.com 網域。
本版需將 index.html、script.js、style.css、content-keys.js、favicon.ico 及 assets 資料夾一起上傳原網站儲存庫根目錄。
README.md 與 CHANGELOG.md 是維護文件，建議一併上傳。此資料夾沒有 Git 遠端設定，不能據此判定部署分支。
不要更動原 GitHub 上的 CNAME；apps-script 與原始 LOGO 資料夾不用上傳到網站。

GAS 程式碼在原專案更新後，使用「管理部署作業 → 編輯 → 建立新版本」更新現有部署，
即可沿用原 /exec 網址。不要把 Google 試算表 /edit 共享網址填入 GAS_URL。
新增或修改 B 欄內容不需要重新部署 GAS。

## 地址與導航維護

在「聯絡我們」分頁修改以下 B 欄即可：

- 園區地址：完整地址。地圖、地址連結及導航按鈕共用這個值，不用另填地圖網址。
- 導航按鈕文字：例如「開啟 Google Maps 導航」；留白則使用預設文字。
- 顯示位置資訊：勾選才顯示地圖卡片及上方「我們在哪裡」入口。取消勾選只隱藏，不刪除地址。

這三個新欄位由現有 GAS 原樣回傳中文名稱，script.js 直接讀取，不需修改 content-keys.js 或重新部署 GAS。
不要為新增欄位重跑一次性 renameKeysToChinese；它只用於先前既有資料的中文化。
地址空白或資料讀取失敗時，位置區不顯示，避免使用過期地址。更新試算表後重新整理網站即可。
導航預設開車模式、以裝置目前位置作為起點。App 是否開啟／直接導航取決於裝置與定位權限；可能先顯示路線預覽。
地圖直接嵌入 Google Maps，避開搜尋頁轉址。地圖內可操作縮放，地址與獨立按鈕負責開啟導航。
位置區直接融入深藍頁尾：桌機左側地址、右側地圖；手機先地址與導航、再地圖。
不再顯示常駐載入／失敗提示，地址旁保留「查看 Google 地圖」連結作為預覽遭阻擋或服務異常時的替代入口。
未經入口定位核對的地址可能由 Google 判定至鄰近道路，首次請自行確認實際到達位置。

## 產品顯示控制

「產品」分頁 B12 為整區開關，B13、B14、B15 分別控制產品1、2、3卡片。
取消勾選只隱藏，不刪除原本內容；全部卡片關閉或整區關閉時，頁面與導覽的產品入口一起隱藏。
剩餘卡片會依數量重新排列。尚未讀取到後台時先隱藏產品區，避免已關閉的商品短暫出現。
四個新中文參數由既有 GAS 原樣回傳，無須重新部署；缺少新欄位的舊資料仍預設顯示。

## 輪播與網站識別

輪播在內容請求完成後初始化一次；每次重新設定都會清除舊計時器與事件。
照片依編號排序，無固定張數上限；新增列仍用「果園照片8、果園照片9」等名稱與公開圖片網址。
自動播放間隔5秒，可按暫停；滑鼠停留、鍵盤焦點進入、切換分頁及偏好減少動態時暫停。
只有一張照片時不自動播放，空清單顯示「果園照片準備中」。

assets/favicon.svg 為藍色小山向量圖；favicon.ico、favicon-32.png、apple-touch-icon.png 為相容尺寸。
assets/share-logo.jpg 是原版 LOGO 的完整副本，保留不覆寫。
目前分享圖片使用 assets/share-cover-20260919.png（1733×907），為以原 LOGO 為參考製作的米白與霧藍山景封面。
封面透過內建圖像生成工具製作並目視檢查，並非原 LOGO 的逐像素貼上；品牌原始檔仍保留供後續精確製版使用。
分享資訊直接寫在 HTML，供分享平台抓取；LINE 自行決定卡片樣式，網站只能提供圖片、標題及摘要，不能強制大型橫幅。
上線後圖片網址才會公開生效；LINE、Facebook 等平台可能保留舊預覽快取，不代表檔案未更新。

## 字體與視覺

首頁與各區標題、FAQ問題、中文品牌文字及園區資訊數值使用 Huninn（粉圓）400字重，不額外模擬粗體。
正文、導覽及按鈕維持 Noto Sans TC（思源黑體），載入400與500字重。粉圓無法載入時依序使用思源黑體、蘋方、微軟正黑體與系統黑體。
首頁主內容上限維持1040px、說明文字720px，主標題保留均衡換行。
本版樣式網址版本為20260920-huninn；原試算表、GAS、產品及地址控制欄位皆不變。

## 每次更新的交付格式

每次修改均在 CHANGELOG.md 新增日期與更新標題，列出更新內容、驗證結果、上傳檔案與未完成事項。
回覆使用者時同樣提供「更新標題」「更新內容」「GitHub 上傳清單」「部署狀態」，不要把暫存修改稱為已套用正式檔案。
